1. Источники

Принимаются vk.ru, vk.com, m.vk.com, короткие имена, club123, public123 и id123. Клип-ссылки здесь не обрабатываются — это парсер стен.
Сбор комментариев выполняется после загрузки постов каждого источника.
Ответы: до 10 из каждой ветки (если доступны). Большие ветки могут быть неполными. Данные не включают удалённые или закрытые комментарии.

Токен ВК остаётся в памяти страницы и никогда не отправляется в GitHub. Доступ к закрытым публикациям не запрашивается.

2. Автоматическая передача результатов для анализа

Создайте отдельный Private репозиторий. Для токена выберите доступ только к нему и разрешение Contents: Read and write. Токен не сохраняется в браузере, GitHub или CSV. Не отправляйте его в чат. Встроенная проверка не позволит загружать данные в публичный репозиторий.

Передача отключена. Вы по-прежнему можете скачивать CSV вручную.

5. Поиск новых авторов

Ищем неизвестные страницы по тематическим публикациям и/или по активности в сообществах, где есть ЦА. Затем проверяем открытые стены, реальные просмотры, регулярность публикаций и число подписчиков. Поиск не гарантирует полноту ВК.

Метод newsfeed.search ищет публичные посты, не авторов по имени. Доступность зависит от прав VK API.
